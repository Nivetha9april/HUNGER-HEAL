# 🍱 HungerHeal

**HungerHeal** is a mobile and web application aimed at connecting **donors**, **recipients**, and **volunteers** to reduce food waste and redistribute excess food to those in need.

## 🚀 Features

- Secure authentication for Donors, Recipients, and Volunteers
- OSM integration for real-time location tracking
- Volunteer scheduling and trackinG
- AI chatbot for user assistance (Dialogflow/OpenAI)
- Leaderboards and social recognition for active volunteers
  

## 📱 Tech Stack

| Layer        | Technology                            |
|--------------|----------------------------------------|
| Frontend     | Flutter                                |
| Backend      | Firebase, Node.js                      |
| Maps         | OSM Maps API                           | 
| Auth         | Firebase Auth                          |
| Database     | Firebase Firestore + Realtime Database |
| AI Chatbot   | Dialogflow / OpenAI                    |
| Others       | JWT, REST APIs / GraphQL               |
